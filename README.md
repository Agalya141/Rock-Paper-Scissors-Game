# ✊✋✌️ Rock Paper Scissors Game

A simple Rock Paper Scissors game built with **HTML, CSS and JavaScript**. Play against the computer, track your score, and see how long your win streak can get!

🔗 **Live Demo:** [Play the game](https://agalya141.github.io/Rock-Paper-Scissors-Game/)

---

## ✨ Features

- 🎯 Choose Rock, Paper or Scissors
- 🤖 The computer plays a random move
- 🏆 Instant Win, Lose or Tie result
- 📊 Live scoreboard (Wins, Losses, Ties)
- 💾 Score is saved in the browser using `localStorage`, so it stays after a page refresh
- 🔥 Win streak counter (resets on a loss, a tie or when the Reset button is clicked)
- 🔄 Reset button to clear the score and the streak

---

## 🛠️ Built With

- **HTML**: structure of the game
- **CSS**: styling and layout
- **JavaScript**: game logic, DOM manipulation, event handling and `localStorage`

---

## 🚀 How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Agalya141/Rock-Paper-Scissors-Game.git
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

No installation or build step is needed.

---

## 🎮 How to Play

1. Click Rock, Paper or Scissors.
2. The computer picks a random move.
3. The result and the updated score appear on the screen.
4. Win again and again to build your streak. 🔥
5. Click **Reset Button** to start fresh.
